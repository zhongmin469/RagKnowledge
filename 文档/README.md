## 维护约定

1. 新增需求、设计文档放入 `需求与设计/`；
2. 每阶段验收报告放入 `验收报告/`，文件名统一为“阶段编号 + 主题 + 验收报告”，例如 `V5-1 多格式解析与知识库筛选验收报告.md`、`V5-2 格式保真与依赖修复验收报告.md`；v6 版本以此类推使用 `V6-1`、`V6-2` 前缀。
3. 安装、运维、开发教程放入 `开发运维指南/`；
4. 审计、缺陷排查、测试修复类文档放入 `测试与质量/`；
5. 验收截图继续放根目录 `docs/<阶段>-screens/`，报告中用相对路径引用，不随文档移动。
